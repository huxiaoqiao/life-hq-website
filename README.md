Life HQ 的官方网站：本地优先的 AI 人生参谋，装在你自己的电脑和手机上。

- 官网（中文）：计划部署于 lifehq.vip
- 产品购买：[淘宝商品页](https://item.taobao.com/item.htm?ft=t&id=1096984688103)

## 本地预览

纯静态站点，无构建、无依赖、无跟踪脚本——直接用浏览器打开 `index.html`，或：

```bash
# 任意静态服务器，例如
npx serve .
python -m http.server 8000
```

## 技术说明

- **纯静态 HTML/CSS**：零 JavaScript、零跟踪、零外部依赖（图标为内联 SVG）。
- **设计令牌与桌面应用同源**：`css/shared.css` 的色彩/圆角/阴影变量与 Life HQ 桌面端样式体系一致（主色 `#4f46e5`、正文 `#1c2444`、画布 `#f3f6ff`），改主题只需改 `:root` 一处。
- **响应式**：960px / 640px 两档断点，移动端可用。
- 插画素材位于 `assets/`。
